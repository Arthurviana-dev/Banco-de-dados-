# Sistema de Gerenciamento de Usuários e Livros

Projeto de estudo desenvolvido em Python para demonstrar o uso do **SQLAlchemy (ORM)** com o banco de dados **SQLite**. O objetivo é gerenciar usuários e seus respectivos livros de forma automatizada.

## 🛠️ Tecnologias Utilizadas
* Python 3
* SQLAlchemy (ORM)
* SQLite

## 🚀 Como Executar o Projeto
1. Clone o repositório:
   `git clone https://github.com/Arthurviana-dev/Banco-de-dados-.git`
2. Instale as dependências:
   `pip install sqlalchemy`
3. Execute o arquivo principal:
   `python database.py`
